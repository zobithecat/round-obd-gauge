# Mock iCar Pro (IOS-Vlink)

ESP32 기반 가짜 OBD2 BLE 어댑터. 실제 차량 없이 게이지 디바이스 테스트용.

## 하드웨어

- ESP32 보드 아무거나 (ESP32-WROOM, ESP32-S3 등)

## BLE 설정

| 항목 | 값 |
|------|-----|
| Device Name | `IOS-Vlink` |
| Service UUID | `18F0` |
| RX (Notify) | `2AF0` |
| TX (Write) | `2AF1` |

## 업로드

```bash
# Arduino IDE 또는 PlatformIO
# 보드: ESP32 Dev Module
# 파티션: Default 4MB
```

## 시리얼 명령어

시리얼 모니터(115200 baud)에서:

| 키 | 동작 |
|----|------|
| `1` | 공회전 모드 (RPM 750-900, 속도 0) |
| `2` | 일반 주행 모드 (RPM 1500-3000, 속도 40-80) |
| `3` | 스포츠 주행 모드 (RPM 4000-7000, 속도 100-180) |
| `4` | 과열 시나리오 (수온 점점 상승) |
| `s` | 현재 상태 출력 |
| `r` | 수온 85°C로 리셋 |
| `h` | 도움말 |

## 지원 OBD2 PID

### Mode 01 (현재 데이터)
| PID | 설명 |
|-----|------|
| 00 | 지원 PID |
| 01 | MIL 상태 |
| 04 | 엔진 부하 % |
| 05 | 냉각수 온도 |
| 0C | RPM |
| 0D | 차량 속도 |
| 0F | 흡기 온도 |
| 11 | 스로틀 위치 % |
| 2F | 연료 레벨 % |

### Mode 09 (차량 정보)
| PID | 설명 |
|-----|------|
| 02 | VIN (MOCKVIN1234567) |

## 지원 AT 명령어

- `ATZ` - 리셋
- `ATE0/1` - 에코 끄기/켜기
- `ATH0/1` - 헤더 끄기/켜기
- `ATS0/1` - 공백 끄기/켜기
- `ATSP x` - 프로토콜 설정
- `ATRV` - 배터리 전압
- `ATI` - 디바이스 정보
- `ATDP` - 현재 프로토콜

## 테스트 시나리오

### 1. 기본 연결 테스트
1. Mock 디바이스 전원 ON
2. 게이지 디바이스에서 `IOS-Vlink` 스캔 & 연결
3. ATZ, ATE0 등 초기화 확인

### 2. 데이터 표시 테스트
1. 공회전 모드(`1`)로 시작
2. 게이지에 RPM, 속도 표시 확인
3. 주행 모드(`2`)로 변경, 값 변화 확인

### 3. 경고 테스트
1. 과열 모드(`4`) 활성화
2. 수온 100°C 이상 시 게이지 경고 확인

## 추가 PID 필요 시

// PID XX - 설명
if (pid == "XX") {
  sprintf(response, "41%sXX%s%02X", sep.c_str(), sep.c_str(), value);

}
